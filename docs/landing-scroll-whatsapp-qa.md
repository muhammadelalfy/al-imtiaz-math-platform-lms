# Scroll and WhatsApp Landing Verification

The public landing was reviewed in the managed preview at `1280×900` and `390×844`. The GSAP ScrollTrigger sections load without disrupting the initial Arabic RTL hero, and the reduced-motion branch keeps motion out of the user path when requested by the browser.

The WhatsApp action is fixed at the lower left on desktop and collapses to an icon-only, accessible control on mobile. It remains reachable without covering hero controls or primary reading content. The current destination opens WhatsApp with a prefilled enquiry; it does not include a teacher phone number or provider credential, which should be configured only when the project owner approves a production contact destination.
